# Ems Tool
## Get Start
1. Install [.Net 10 SDK](https://dotnet.microsoft.com/en-us/download)
2. Install VSCode or VS2026
3. clone repo
4. set project 'org.Ui.Poseidon' as startup project
5. change 'target platform' to x64
6. restore solution
7. build & run 'org.Ui.Poseidon'
